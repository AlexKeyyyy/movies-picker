# movie-picker-front

Это приложение предназначено для просмотра популярных фильмов с динамическим поиском.

## Доступные команды

В каталоге проекта доступны следующие команды:

### `yarn dev`

Запускает приложение в режиме разработки.
Откройте [http://localhost:5173/](http://localhost:5173/), чтобы увидеть приложение в браузере.

Страница будет автоматически обновляться при изменениях в коде.

### `yarn build`

Создаёт оптимизированную сборку приложения для продакшена в папке `build`.

---

## О приложении

movie-picker-front позволяет просматривать список популярных фильмов с постерами, годами выпуска и рейтингами. Реализован динамический поиск по названию фильмов, который обновляет список результатов в реальном времени. У зарегестрированных пользователей есть возможность добавлять фильм в список "К просмотру" и высттавлять собственные оценки.
