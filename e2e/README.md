# 📁 E2E тесты для Movies Picker

Данная директория содержит **end-to-end тесты** для веб-приложения Movies Picker (React + Go), написанные с использованием [Playwright](https://playwright.dev/). Тесты проверяют основные пользовательские сценарии: регистрация, авторизация, поиск фильмов, работа со списком «Смотреть позже», выставление рейтингов и защиту маршрутов.

---

## 📋 Предварительные требования

1. **Node.js** версии 18 или выше.
2. **Запущенное приложение** (фронтенд + бэкенд + БД) в фоновом режиме.  
   Подробнее о запуске приложеня можно узнать в файле README.md в корне проекта и на GitHub

---

## 🚀 Установка и запуск тестов

1. Перейдите в папку `e2e`:
   ```bash
   cd e2e
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите тесты:
   - **Без открытия браузера** (результат в консоли):
     ```bash
     npm test
     ```
   - **С открытым браузером** (позволяет наблюдать за выполнением):
     ```bash
     npm run test:headed
     ```

4. Просмотр HTML-отчёта:
   ```bash
   npm run report
   ```
   Отчёт будет доступен по адресу `http://localhost:9323`.

## 📂 Структура папки

```
e2e/
├── package.json          # зависимости и скрипты
├── package-lock.json
├── playwright.config.ts  # конфигурация Playwright
├── tsconfig.json         # настройки TypeScript (опционально)
├── tests/                # сами тесты
│   ├── auth.spec.ts      # регистрация, вход, выход
│   ├── movies.spec.ts    # поиск и детали фильмов
│   ├── profile.spec.ts   # доступ к профилю без авторизации
│   ├── ratings.spec.ts   # выставление рейтинга
│   ├── watchlist.spec.ts # добавление и удаление из «Смотреть позже»
│   └── helpers.ts        # вспомогательные функции (генерация email, регистрация, логин)
├── playwright-report/    # генерируемый HTML-отчёт (игнорируется git)
└── test-results/         # артефакты упавших тестов (игнорируются git)
```

## 🔧 Настройки

- **Пароль по умолчанию** для тестового пользователя: `Password123!` (удовлетворяет требованиям: заглавная буква, цифра, спецсимвол, длина ≥8).
- **Базовый URL** приложения: `http://localhost:3000` (можно изменить в `playwright.config.ts`).
- **Таймауты**: 30 секунд на тест, 10 секунд на ожидание элементов (настраиваются в конфиге).

---

## 🧹 Очистка

После запуска тестов в папках `playwright-report` и `test-results` могут оставаться артефакты. Они добавлены в `.gitignore` и не попадут в репозиторий. Для ручного удаления выполните:

```bash
rm -rf playwright-report test-results
```

## 💬 Поддержка

Если тесты падают или нужна помощь, проверьте:
- Запущено ли приложение (`http://localhost:3000` открывается в браузере).
- Нет ли ошибок в консоли разработчика.
- Соответствуют ли селекторы текущей вёрстке (можно обновить с помощью Playwright Codegen).
